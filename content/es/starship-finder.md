# Naves

**¿Qué formas puede tener una nave?** Esta página monta una exótica, una nave solar, un combatiente, un transportista, un explorador o un transbordador con sus piezas: elige el tipo, luego las piezas. Cada forma de aquí es una que el juego hace. La búsqueda de un sistema aún no está hecha.

## Cómo usarla

Haz clic en una parte de la nave, o en un nombre debajo de ella, para ver sus opciones; cada recuadro dibuja su parte. Cada elección es una nave que el juego construye, así que ninguna opción aparece en gris. La nave se dibuja en gris liso; una exótica aparece como cuando aterriza, con las alas levantadas.

Una nave exótica tiene uno de dos cuerpos. El cuerpo Real lleva un motor, un par de alas y un ala superior, cada uno de tres formas; uno de los motores admite un segundo juego de propulsores, y dos de las alas superiores llevan uno de cinco detalles. El calamar es el cuerpo raro: alrededor de una exótica de cada 21, siempre con la misma forma.

Una nave solar tiene cuatro partes, cada una de unas pocas formas: las puntas de las alas, las alas, el cuerpo y las velas, dibujadas desplegadas.

Un combatiente tiene un motor, alas y una cabina. La mayoría de las alas vienen con o sin un accesorio, y varias llevan subalas propias; una de las cabinas admite uno de cinco morros.

Un transportista tiene una cabina y un casco. El casco lleva alas, cada una con propulsores y subalas, contenedores laterales y motores; algunos cascos van sin alas.

Un explorador tiene una de dos cabinas, cada una con su cubierta y sus accesorios, y alas que son o un par a juego o un ala izquierda y una derecha propias; un ala puede llevar una punta, subalas o un accesorio.

Un transbordador es simple o doble. Cada tipo lleva sus propias cabinas, cascos, alas, propulsores, lámparas y accesorios, así que las opciones cambian con el cuerpo que elijas.
