# Источники по размеру планеты

**Сколько дает размер планеты?** Много: планета размера «{{highName}}» содержит в медиане {{high}} мест, а «{{lowName}}» — {{low}}: мест меньше, разница {{ratio, plural, one {# раз} few {# раза} many {# раз} other {# раза}}}. Размер масштабирует все источники одинаково, поэтому соотношение источников остается прежним.

Место — это точка сетки планеты, на которой стоит постройка; виды перечислены в разделе [откуда берется мультитул](/about#where-a-multitool-comes-from). Места считаются выше уровня моря, и исключение — затонувшие корабли: они стоят глубоко под водой. Неизведанные системы входят в эти медианы.
