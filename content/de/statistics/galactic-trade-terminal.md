# Terminal des galaktischen Marktes

**Was verkauft das Terminal des galaktischen Marktes?** Hergestellte Produkte und Rohstoffe. Das Terminal einer Raumstation zeigt {{shownMin}} bis {{shownMax, plural, one {# Gegenstand} other {# Gegenstände}}} aus einer Liste von {{wares}}; jedes andere Terminal, auf einem Planeten, einem Frachter oder der Weltraum-Anomalie, zeigt {{shownMin2}} bis {{shownMax2}} aus einer Liste von {{wares2}}. Ein Teil jeder Liste ist immer im Angebot, der Rest wird gezogen.

## Auf einer Raumstation

Jeder Gegenstand, den das Terminal einer Station zeigen kann, mit der Beschreibung, die das Spiel ihm gibt, und seinem Grundwert. Der Preis an einem Terminal bewegt sich mit der [Wirtschaft](/guides/economy) des Systems um diesen Wert. Hinter dem Terminal der Station steht der [Schrotthändler](/guides/scrap-dealer), der gegen unreines Metall verkauft.

## Auf einem Planeten, einem Frachter oder der Weltraum-Anomalie

Jedes Terminal außerhalb einer Raumstation, an einem Handelsposten, in einer Siedlung, an Bord eines Frachters oder in der Weltraum-Anomalie, hat weitgehend dieselbe Liste und fügt Raumschiffstart-Treibstoff, Navigationsdaten und die Exo-Anzug-Upgrade-Karte hinzu. Der Marktplatz einer Siedlung hat außerdem einen [Technologie-Kaufmann der Siedlung](/guides/settlement-technology-merchant), der hergestellte Komponenten verkauft.

<!-- widget:stock2 -->

Die Piloten, die neben einem Terminal landen, handeln ebenfalls aus ihren Schiffen, wie [Raumschiffpilot](/guides/starship-pilots) auflistet.
