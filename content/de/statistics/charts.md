# Karten

**Wo bekommst du eine Karte, und was findet jede?** Die meisten kommen vom [Kartografen](/guides/cartographer) einer Raumstation gegen Navigationsdaten; der Rest von einem [Außenposten im Weltraum](/guides/deep-space-outpost), dem [Schrotthändler](/guides/scrap-dealer), Wächtern, der Holo-Arena und dem Herstellungsmenü. Jede markiert einen Ort auf deiner Karte.

## Jede Karte

<!-- widget:charts -->

Eine Karte durchsucht den Planeten oder das System, in dem du bist, und die meisten markieren den nächsten Ort ihrer Art. Eine Siedlungskarte wählt irgendeine Siedlung des Planeten, und die Karte bewohnbarer Asteroiden und die Einladung des Champions können in ein nahes System führen.

## Was eine Planetenkarte markiert

Der Kartograf verkauft vier Sorten von Planetenkarten. Jede markiert ein Gebäude, gezogen nach den Chancen unten, also wähle die Sorte nach dem, was du suchst: eine Notfall-Karte für einen abgestürzten Frachter oder ein Notsignal, eine kommerzielle für einen Shop oder eine Grabungsstätte, eine Alien-Karte für einen Monolithen oder eine Ruine, eine geheime für ein Depot, eine Verarbeitungsanlage oder eine Fabrik.

Das eigene Sortiment des Kartografen, mit dem Preis jeder Karte, steht im Ratgeber [Kartograf](/guides/cartographer).
