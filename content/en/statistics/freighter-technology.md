# Freighter technology

**What can a freighter upgrade module raise?** The hyperdrive and each kind of frigate expedition have their own family, from C to S, and most raise one stat: an S-Class freighter hyperdrive upgrade adds {{hyperdriveS}} of range. No merchant sells them. They come from three places:

- **A derelict freighter.** The [Scrap Dealer](/guides/scrap-dealer), behind the Galactic Trade Terminal of a station, sells the place of one, {{derelictFirst}} units the first time and {{derelictSecond}} the second. At its engineering control panel, pick Fabricate Items, then Fabricate Technology Upgrade. It gives one freighter module of any class, C to S, or now and then a starship reactor instead. A freighter module from it is class C {{derelictC}} of the time, B {{derelictB}}, A {{derelictA}}, and S {{derelictS}}. Its walk from the hangar to that panel is the quest [Lost in Space](/quests/lost-in-space).
- **A destroyed pirate dreadnought.** It gives one module, always at class S, as [freighter modules](/guides/freighter-modules) shows. The rare class A item it gives instead is a starship reactor, not a freighter module.
- **The Hive of Glass.** The boss of the Swarm expedition could give a class S module too; it could be fought only in that expedition, which has ended.

Every module on this page has the numbers of its system: the same place gives the same module again.

Each stat reads as the module's card prints it.

## Every freighter module

The modules you build or receive, apart from upgrade modules. The Resonance Matrix, which takes the freighter to the purple stars, is a Capital Ship Research blueprint, bought for Salvaged Frigate Modules, and the quest [In Stellar Multitudes](/quests/in-stellar-multitudes) gives it too.

## Upgrade modules

One table per family: each class, how many stats one install raises, and the limits of each stat. Below each table a second one shows what one install rolls: how many stats it raises, how often it comes near the best its kind can add to the stat it names, and how often each stat is raised; a third shows how often a raised stat lands in the top tenth of its limits.

### Freighter Hyperdrive

The freighter's hyperdrive modules climb by class with no overlap: no A-Class install reaches the worst S-Class one in Hyperdrive Range. So every class up is a sure gain, and a derelict freighter that hands you an S-Class module has given you the best there is for that place.

### Expedition Speed Control

<!-- widget:frSpeedRolls -->

<!-- widget:frSpeedTop -->

An S-Class Speed Control module always adds the same Expedition Speed, and no A-Class install reaches it. There is nothing to roll for at S: the first one is as good as the last.

Mining Control closes the set the same way. Across all six expedition families the rule is one: an S-Class module is the ceiling, and which family to fill first depends only on the expeditions your [frigates](/guides/frigates) fly.
